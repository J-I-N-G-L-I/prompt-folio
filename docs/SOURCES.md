# Official references and verification boundaries

Documentation consulted: 2026-09-08. Paths are explanatory; availability and translated UI labels can differ. No signed-in all-app certification is claimed.

## AI service setup

- **ChatGPT** (`chatgpt-user`): [Settings → Personalization → Custom Instructions](https://help.openai.com/en/articles/8096356) — 2026-09-08.
- **Claude** (`claude-user`): [Settings → Instructions for Claude](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features) — 2026-09-08.
- **Gemini** (`gemini-user`): [Settings & help → Personal Intelligence → Instructions for Gemini → Add → Submit](https://support.google.com/gemini/answer/16598625) — 2026-09-08.
- **Microsoft 365 Copilot** (`copilot-user`): [Settings and more (…) → Chat settings → Personalization → Custom instructions → Edit instructions → Save instructions](https://support.microsoft.com/en-us/microsoft-365-copilot/customize-how-microsoft-365-copilot-responds-to-you) — 2026-09-08.
- **Perplexity** (`perplexity-user`): [Profile icon → Personalize → Introduce yourself](https://www.perplexity.ai/help-center/en/articles/10352990-account-settings) — 2026-09-08.
- **ChatGPT · Projects** (`chatgpt-project`): [Open project → ⋯ → Project settings → Project instructions](https://help.openai.com/en/articles/10169521) — 2026-09-08.
- **Claude · Projects** (`claude-project`): [Open project → Set project instructions → Save instructions](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects) — 2026-09-08.
- **Gemini · Gems** (`gemini-project`): [Web app → Gems → New Gem → Instructions → Save](https://support.google.com/gemini/answer/15146780?co=GENIE.Platform%3DDesktop&hl=en) — 2026-09-08.
- **Perplexity · Projects** (`perplexity-project`): [Projects → Open project → Settings → Context → Instructions](https://www.perplexity.ai/help-center/en/articles/10352961-what-are-spaces) — 2026-09-08.
